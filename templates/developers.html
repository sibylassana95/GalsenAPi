API GalsenAPI v1

Une API REST publique, paginée, filtrable et documentée. Aucune clé requise pour un usage standard — limité à 60 requêtes/minute par adresse IP.

Exemples

Bon usage

  • • 60 requêtes/minute par IP (anonyme), 120/minute authentifié.
  • • Citez la source des données (ANSD, FAO, Banque mondiale, NOAA, HDX…) et respectez leurs licences.
  • • Les exports volumineux (GeoJSON ~29 Mo) sont cachés 30 minutes — réutilisez le cache plutôt que de re-télécharger.
  • • Un bug, une donnée incorrecte ? Ouvrez une issue GitHub.
